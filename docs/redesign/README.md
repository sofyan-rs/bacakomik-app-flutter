# BacaKomik Redesign

Redesign aplikasi BacaKomik (Flutter) dengan design system Dotline.

- `DESIGN_SYSTEM.md` — token, tema Flutter, komponen, dan peta layar ke kode.
- `screens/` — 12 layar + perbandingan ikon, PNG @2x (390pt lebar).
- `app-icon/` — ikon B · Panel: adaptive icon + monochrome (Material You), legacy, Play Store 512.
- `assets/fonts/` — Geist, Geist Mono, Doto (TTF statis, OFL 1.1).
- `assets/icons/lucide/` — ikon Lucide yang dipakai, stroke 1.5.
- `assets/images/splash-art.webp` — ilustrasi splash tanpa bingkai.
